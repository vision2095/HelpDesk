The tests use temporary profiles and controlled AI/payment responses. They do not prove live provider access, real email delivery, Stripe acceptance, Windows runtime behavior, Intel hardware behavior, physical audio capture, or third-party application shortcut compatibility. No third-party API credentials were sourced or used.

The supplied Windows ZIP contained one 2.1 MB `ctfmon.exe`. It was statically classified as a PE32+ x86-64 executable and was not launched. The supplied screenshots were used as feature evidence; the binary was not treated as an installer or executed as part of setup.

Public deployment still needs the owner's domain/host, production SMTP, Stripe keys/webhook, encryption secret, funded AI provider, backups, privacy/support details, and publisher signing/notarization. Remote CI was not run. This version does not claim complete HintLens/Evadus parity or production readiness.

See [REFERENCE_PARITY.md](REFERENCE_PARITY.md) for the supplied screenshot comparison and remaining gaps, and [IMPLEMENTATION_CHECKLIST.md](IMPLEMENTATION_CHECKLIST.md) for the engineering backlog.

Build recovery: the first packaging attempt failed with ENOSPC. Redundant generated 1.2.0 installers, old ZIP duplicates, redundant 1.2.0 app backups and an incomplete build directory were removed from this project. Rollback copies and 1.2.1 DMG/Windows artifacts were retained. Both Mac architectures and the Windows installer were then rebuilt successfully and verified.
