# Mac landscape and workspace layout repair

Floating mode previously opened at 480×640 while keeping a fixed-width bundle and a large unshrinkable opacity control beside wrapping action buttons. This compressed the chat to a few lines and stacked the toolbar vertically.

Floating mode now opens at 1040×620, constrained to the active monitor's work area, including monitors with negative coordinates. Minimum resize dimensions are 720×420, reduced as necessary on small screens. Normal workspace bounds also fit the work area and reopen in landscape instead of restoring an oversized portrait window. Existing product identity, preferences and user data are retained.

The overlay uses a proportional bundle column, a horizontal action row, a separate opacity/mouse control row and an optional scrollable Keys drawer. Scrollable content can shrink without collapsing the composer or toolbar. Long model names truncate. Settings dialogs retain accessible headers and footers with scrollable tabs. Restored missing settings button styles and aligned checkbox controls. Microphone controls now match workspace styling; short desktop viewports keep the composer visible; sidebar content can scroll; settings columns can shrink without forcing horizontal overflow.
