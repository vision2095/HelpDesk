- The main bundle hint says Ctrl+Shift+D while screenshot badges/settings show Shift+S. Browser settings text says Ctrl+Shift+G while the Hotkeys Browser row shows Shift+D. REF-21 shows both Ctrl+Shift+M in explanatory text and Shift+M in its mouse badge. These are observed differing labels; they do not establish release defaults, successful binding changes, or actual registered keys.
- The BG 100% slider is separate from Browser Page zoom 100%. Exact BG and gesture slider endpoints, step size and full control ranges cannot be recovered from these photographs.
- Values such as text colors, 65 WPM and 58/61/65% are observed states. Except where the UI explicitly says otherwise, they are not proven factory defaults. The mouse settings explicitly say gestures are off by default.
- The photographs contain no successful answer generation, populated capture bundle, connected local-model list, browser page, visible radial wheel, live recording result, successful payment, error recovery, or completed login/OAuth sequence. Expected behavior can be specified from labels/descriptions but requires independent implementation tests.
- The reference executable has not been executed in a Windows runtime during this audit. Capture exclusion, cross-app shortcuts, system audio, typing timing, network routes and persistence are not established by photos or strings.
- No evidence here establishes a reference REA runtime plugin. REA is used for developer investigation; see ENVIRONMENT_REPORT.md.
